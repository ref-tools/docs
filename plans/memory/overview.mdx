## Stop teaching every agent the same things

Your preferences, corrections, and project context should carry over when you switch agents.

Ref gives that knowledge a shared home. With Ref memory active, agents save useful things they learn as you work and recall them in later conversations. No special prompt required.

- **Switch agents without starting over.** A preference learned in Anthropic’s Claude Code can inform your next review in OpenAI’s Codex.
- **Make corrections last.** Feedback becomes context for future work, instead of disappearing with the chat.
- **See what’s remembered.** Memories are readable refs you can inspect and correct.

## Learn once, use across agents

During a review, you tell Claude Code:

> Lead with the user-visible behavior, then explain the implementation and validation.

Claude Code can save that preference. Later, Codex can use it without you explaining your review style again. Both agents use the same Ref account and space.

Change your mind? Say so naturally:

> Going forward, put risks and limitations before implementation details.

The agent can update the memory for future work.

## What gets remembered?

Lasting preferences, corrections, project context, and useful references. The agent decides what is worth keeping; memory is not a transcript of everything you say.

Memories are yours to inspect and correct. Ask your agent what it remembers or open the records in Ref. Your current instructions take precedence over remembered preferences.
