How to set up the Ref Plans MCP server with [Claude Code](https://www.claude.com/product/claude-code).

## Recommended: install script

The [one-line installer](/plans/install#install-with-one-command) sets up Claude Code with the `ref` CLI, hooks, and the Ref MCP server. It signs you in through the browser — no API key needed:

```sh
curl -fsSL https://api.plan.ref.tools/plugins/install/local-agent | bash
```

Use this script for the local agent review loop. `AwaitReview` and `Share` are API-key only, and an OAuth connection does not include them.

## Manual install

Add the server with no API key, then sign in:

```
claude mcp add --transport http ref https://api.plan.ref.tools/mcp
```

In Claude Code, run `/mcp` and choose `Authenticate`. Sign in on Ref's page.

For plan-specific mode:

```
claude mcp add --transport http ref "https://api.plan.ref.tools/mcp?plan=<PLAN_ID>"
```

To use a specific team, see [Team-scoped access](/plans/install#team-scoped-access).

## API key

```
claude mcp add --transport http RefPlan https://api.plan.ref.tools/mcp --header "x-ref-api-key: <YOUR_API_KEY>"
```

You can find your API key at [ref.tools/keys](https://ref.tools/keys).

For plan-specific mode, append the plan ID:

```
claude mcp add --transport http RefPlan "https://api.plan.ref.tools/mcp?plan=<PLAN_ID>" --header "x-ref-api-key: <YOUR_API_KEY>"
```

## Verify

Run the command:

```
claude mcp list
```

You should see:

```
➜  claude mcp list
ref: https://api.plan.ref.tools/mcp (HTTP)
```
