## Install Steps

1. Open the VS Code command palette `Shift + Command + P (Mac)` or  `Ctrl + Shift + P (Windows/Linux)`
2. Type `mcp` and select the `MCP: Add server...` action.
3. Select the `HTTP` option.
4. Enter Server URL `https://api.plan.ref.tools/mcp`
5. Enter Server ID `RefPlan`

VS Code asks you to sign in. Sign in on Ref's page.

For plan-specific mode, use `https://api.plan.ref.tools/mcp?plan=<PLAN_ID>`. To use a specific team, see [Team-scoped access](/plans/install#team-scoped-access).

## API key

You can find your API key at [ref.tools/keys](https://ref.tools/keys).

Enter Server URL `https://api.plan.ref.tools/mcp?apiKey=<your-api-key>` instead. For plan-specific mode, use `https://api.plan.ref.tools/mcp?plan=<PLAN_ID>&apiKey=<your-api-key>`.

## Verify

1. Open the Chat UI.
2. In the chat input box, you should see a tools icon next to the send message icon. Click it.
3. This should open the `Configure Tools` menu. You should see `MCP Server: RefPlan` with tools enabled.
