## Install Steps

1. Open `Settings`
2. Click `Apps & Connectors`. In some versions this menu is `Plugins`.
3. If you are not already in developer mode, scroll to the bottom and click `Advanced settings` and toggle on Developer mode.
4. Click `Create` (or `Add custom MCP server`).
5. Fill in Name as `RefPlan`
6. Fill in MCP Server URL `https://api.plan.ref.tools/mcp`
7. Under Authentication select `OAuth`.
8. Check the `I understand` box and click Create.

ChatGPT discovers the sign-in on its own and requests the `plans` scope. Sign in on Ref's page.

For plan-specific mode, use `https://api.plan.ref.tools/mcp?plan=<PLAN_ID>` as the URL. To use a specific team, see [Team-scoped access](/plans/install#team-scoped-access).

## API key

To connect with an API key instead, use `https://api.plan.ref.tools/mcp?apiKey=<YOUR_API_KEY>` and select `No authentication`. You can find your API key at [ref.tools/keys](https://ref.tools/keys).

For plan-specific mode, use `https://api.plan.ref.tools/mcp?plan=<PLAN_ID>&apiKey=<YOUR_API_KEY>`.

## Verify

1. To use Ref Plans, click the `+` button in the left of the prompt input, go to `More` and select `RefPlan`.
2. Ask the agent to list your plans or read a specific plan.
