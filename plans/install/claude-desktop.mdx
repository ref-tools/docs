## Install Steps

1. In Claude, open `Settings` → `Plugins`
2. Add a custom connector
3. Fill in Name as `Ref`
4. Fill in Remote MCP Server URL `https://api.plan.ref.tools/mcp`

Claude shows `Sign in now`. Sign in on Ref's page.

Connectors you add on the web or in Claude Desktop also appear in Claude's mobile apps.

For plan-specific mode, use `https://api.plan.ref.tools/mcp?plan=<PLAN_ID>` as the URL. To use a specific team, see [Team-scoped access](/plans/install#team-scoped-access).

## Verify

Start a new chat and ask Claude to list your plans or read a specific plan.
